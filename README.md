# File Grouper

VS Code のエクスプローラーに、フォルダ直下のファイルを拡張子ごとにまとめて表示するツリービュー「File Grouper」を追加します。グループは1つずつ開閉できるので、今は要らない種類のファイルを畳んで隠せます。

実際のファイルやフォルダには一切変更を加えません（読み取り専用）。

## 機能

- 実際のフォルダ階層はそのまま表示し、各フォルダ直下のファイルを拡張子のグループ（`.py  3` のようにファイル数付き）にまとめます。
- 初期状態ではグループを畳みます。そのフォルダのグループが1つだけなら開いた状態にします。
- ファイルをクリックすると、VS Code の通常のエディターで開きます（画像は画像プレビュー）。
- ファイル・フォルダの作成と削除、`files.exclude` の変更、ワークスペースフォルダの追加と削除を自動で反映します。タイトルバーの「最新の情報に更新」でも反映できます。
- `files.exclude` に従ってファイルとフォルダを隠します。
- 表示言語は英語と日本語に対応します。

## 使い方

エクスプローラーの中に「File Grouper」のセクションが追加されます。セクションはドラッグで別の場所へ移せます。

## 既知の制限

- 拡張子は最後の1つだけを使います（`types.d.ts` は `.ts`、`archive.tar.gz` は `.gz`）。名前の先頭にしか `.` がないファイル（`.gitignore` など）は「拡張子なし」になります。
- `files.exclude` の `!` で始まる例外パターンと絶対パスのパターン、`.gitignore` による除外（`explorer.excludeGitIgnore`）には対応しません。標準エクスプローラーと表示が違うことがあります。
- パターンとの照合は大文字と小文字を区別します。Windows と macOS では標準エクスプローラーと差が出ることがあります。
- 標準エクスプローラーの表示設定（`explorer.sortOrder`、`explorer.compactFolders` など）には従いません。並び順は固定です（フォルダ → グループ。名前は数字を数値として比べる）。
- ウィンドウを再読み込みすると、開閉状態は初期状態に戻ります。
- ダブルクリックでタブを固定する操作はありません。プレビュー表示にするかどうかは VS Code の設定に従います。
- 単一ルートでもルートのノードを表示するため、標準エクスプローラーより1段深くなります。
- `files.watcherExclude` に含まれる場所での変化は自動では反映されません。「最新の情報に更新」で反映してください。

## インストール

Marketplace には公開していません。VSIX ファイルを作ってインストールします（Node.js 20 以降が必要）。

```bash
npm ci
npm run package
code --install-extension vscode-file-grouper-0.1.0.vsix
```

対象は VS Code デスクトップ版 1.90 以降です。Web 版（vscode.dev）には対応しません。

## 開発

| 用途 | コマンド |
|---|---|
| ビルド | `npm run compile` |
| lint | `npm run lint` |
| 単体テスト | `npm run test:unit` |
| 統合テスト | `npm run test:integration`（画面のない環境では `xvfb-run -a` を付ける） |
| 規則の検査 | `npm run check:rules` |
| VSIX の作成 | `npm run package` |

F5（「Run Extension」）で、テスト用ワークスペースを開いた拡張機能開発ホストが起動します。
